8. Animations & Motion

Section entrance animations

All sections use Crafto's data-anime attribute for scroll-triggered entrance animations. The standard pattern across the homepage is:

data-anime='{ "el": "childs", "translateY": [30, 0], "opacity": [0, 1], "duration": 600, "delay": 0, "staggervalue": 300, "easing": "easeOutQuad" }'

Hover micro-animations (custom CSS in globals.css)

Service / project cardtranslateY(-2px) + box-shadow on hover · 0.25s ease Photo inside cardscale(1.03) on parent hover · 0.5s ease Feature boxtranslateY(-2px) · 0.25s ease Button pressscale(0.97) on :active Brand name (ProcessBand)color rgba(0,0,0,0.3) → 0.75 · 0.3s

Nav scroll behavior

The navbar adds .sr-nav-scrolled when window.scrollY > 20, enabling frosted glass via CSS transition on background and box-shadow.
